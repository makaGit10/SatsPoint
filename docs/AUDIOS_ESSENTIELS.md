# Les 66 phrases essentielles à enregistrer

À enregistrer dans chaque langue : **wolof, seereer, pulaar, joola** au Sénégal, et dans **chaque langue ajoutée depuis la console** (onglet « Langues », pour les autres pays de la zone XOF : son nom `langue.{code}` fait partie des essentielles). Le français est facultatif. Une phrase = un fichier de **15 secondes maximum**.

**Où** : se connecter en super-admin → **Studio audio** → choisir la langue → filtre « Essentielles » → **Mode rafale** (les phrases défilent une par une : appuyer sur le micro, parler, valider, suivante). Ou bien « Déposer un fichier » pour un enregistrement fait avant (mp3, m4a, wav, ogg, opus, note vocale WhatsApp…). Quand une langue est finie : **Publier les brouillons**.
