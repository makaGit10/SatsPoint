# Vidéo de démonstration — 3 minutes, en deux versions (FR / EN)

**Deux vidéos, mêmes images** (le jury choisit) : version française (voix off Rémy, `fr-FR-RemyMultilingualNeural`) et version anglaise (voix off Andrew, `en-US-AndrewMultilingualNeural`), sous-titres anglais incrustés dans les deux.

**Principe : la vraie application, filmée dans l'ordre où Awa l'utilise.** Chaque toucher est visible (cercle doré), et quand Awa touche un haut-parleur, on entend **les enregistrements wolof de la propriétaire** (studio en ligne, publiés). Tournage automatique sur le site en ligne (`montage/tournage.mjs`), montage automatique (`montage/composer.py`).

Ordre imposé par le jury : **problème → solution → impact → prochaines étapes**.

## Production
- Voix off : `python -I tools/video/generer_voix.py` (FR → `voix/`) et `--en` (EN → `voix-en/`).
- Voix wolof de l'application : téléchargées depuis le manifeste public en ligne (`/api/v1/audio/manifeste/wo`) dans `sons-wo/` ; nom de l'article Café Touba : voix enregistrée sur l'article.
- Tournage : `node tools/video/montage/tournage.mjs` (site en ligne, téléphone 390×844, ordinateur 1440×900) ; chaque toucher est horodaté avec le son qu'il déclenche. Le prix dicté est injecté à la place du micro (la reconnaissance du prix elle-même est réelle).
- Montage : `python -I tools/video/montage/composer.py fr|en` → `out/SatsPoint-FR.mp4`, `out/SatsPoint-EN.mp4` (1080p, 30 i/s, ≤ 3:00).
- Jamais le lien NWC ni l'e-mail du super-admin à l'écran (connexion console hors champ) ; le secret 2FA est flouté.
- Le plan 13 est le **vrai paiement** du 18/11 (captures Wallet of Satoshi) ; le plan 14 est l'écran vert de la vraie vente V-000001.
